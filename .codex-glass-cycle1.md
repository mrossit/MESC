# Tarefa: Vidro nativo (Liquid Glass) atrás da tab bar — iOS, ciclo 1

App: MESC, Capacitor (React em `client/` + iOS SPM, sem CocoaPods). Bundle `app.saojudastadeu.mesc`.
A tab bar inferior é 100% web (`client/src/components/mobile-bottom-nav.tsx`), hoje com vidro só de CSS (`.liquid-glass` em `client/src/index.css`). O iOS ignora refração SVG — por isso o vidro "de verdade" não aparecia.

## Objetivo deste ciclo (SÓ iOS, SÓ a tab bar inferior)
Fazer aparecer **vidro NATIVO real** atrás da barra de navegação inferior no iPhone, usando `UIVisualEffectView`:
- No iOS 26+, usar o material Liquid Glass nativo se disponível em runtime (`UIGlassEffect` / `.glass`) via checagem `if #available` + reflexão/`NSClassFromString` para não quebrar build em SDK que não tenha o símbolo; fallback para `UIBlurEffect(style: .systemChromeMaterial)` (ou `.systemUltraThinMaterial`) em iOS < 26.
- A view nativa fica ATRÁS do webview, pinada na safe-area inferior, cobrindo exatamente a faixa da tab bar (altura = `--app-tab-bar-height` + inset inferior).

## Como fazer (abordagem híbrida)
1. Tornar o webview transparente na faixa da tab bar: setar `webView.isOpaque = false` e `webView.backgroundColor = .clear` + `scrollView.backgroundColor = .clear` no AppDelegate/plugin. O CSS da tab bar web já deve ter fundo transparente onde antes tinha `.liquid-glass` (deixe só os ícones/labels/borda fina; remova o `backdrop-filter` que fingia o vidro NESSA barra).
2. Criar um **plugin Capacitor nativo** (Swift) `NativeGlass` que insere e posiciona a `UIVisualEffectView` atrás do webview, respondendo a safe-area/rotação/mudança de tamanho (Auto Layout ancorado no bottom + leading/trailing, altura dinâmica). Expor método JS `NativeGlass.showTabBarGlass({height})` e `hide()`.
3. Chamar o plugin do React quando `capacitor-native` estiver ativo (montagem do `mobile-bottom-nav`), passando a altura calculada. Em web/Android puro, manter o CSS atual (não quebrar PWA/Android).
4. NÃO mexer em Android neste ciclo (fica pro ciclo 2). NÃO mexer em Face ID, Formação, nem outras telas.
